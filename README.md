
## Overview

ExpenseTracker is a comprehensive personal finance application that helps users track, analyze, and manage their expenses. With intuitive visualization tools, filtering options, and secure Google authentication, it simplifies financial management and provides insights into spending habits.

## Try it yourself
https://expense-project-frontend.vercel.app/

## Features

### User Authentication
- Secure login via Google Authentication

### Expense Management
- **Add, Edit, and Delete Expenses**: Full CRUD functionality
- **Detailed Expense Records**: Date, category, amount, description, and notes
- **Data Persistence**: All expenses saved to your account

### Dashboard
- Real-time balance calculation
- Period-based filtering (by year and month)
- Visual representation of expense status

### Transaction History
- Comprehensive list of all expenses
- Advanced filtering options:
  - Filter by month or year
  - Sort by date, amount, or category
- Detailed view of each transaction

### Analytics & Search
- Interactive pie charts for category-based expense analysis
- Visual identification of spending patterns
- Financial summary showing:
  - Total income
  - Current balance
  - Total expenses

## Technologies Used

- React
- TailwindCSS

## Usage

### Authentication
1. Click the "Sign in with Google" button on the homepage
3. Follow the prompts to authorize the application

### Adding Expenses
1. Navigate to the Dashboard
2. Click the "+" button
3. Fill in the required fields:
   - Select a date
   - Choose a category
   - Enter the amount
   - Add a description
   - Include any additional notes (optional)
4. Click "Add" to record your expense

### Viewing and Analyzing Expenses
1. **Dashboard**: View your current balance filtered by your selected time period
2. **Transaction History**: Review all transactions with sorting and filtering options
3. **Search & Analytics**: Explore spending patterns through pie charts and summary statistics
